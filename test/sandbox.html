CryptoJack Guard Sandbox

Test environment to validate cryptojacking detection layers

How to run tests:

  1. Open Chrome and navigate to chrome://extensions
  2. Enable Developer mode (top-right toggle switch).
  3. Click Load unpacked and select the project directory: C:\Users\drish\.gemini\antigravity\scratch\cryptojacking-detector
  4. CRITICAL (if opening this page as a file:/// URL): Click the Details button on the CryptoJack Guard card and turn on the Allow access to file URLs toggle. Otherwise, Chrome blocks extension injection into local files!
  5. Return to this page, click any of the test buttons below, and observe the extension's badge score and popup dashboard logs.

1. Script Signature Scanner

Appends a mock external script tag coinhive.js (matched in signature configurations). The extension should block/flag the signature instantly.

2. Inline Keyword Scanner

Appends an inline script containing miner keywords: cryptonight and stratum+tcp. The extension's static parser should catch it.

3. CPU Thread Heuristics

Launches a recurring main-thread loop for 1.2 seconds, 3 times consecutively. The CPU monitor timing loop should detect the event loop lag.

4. WASM Interceptor (MAIN World)

Instantiates a mock WebAssembly binary using WebAssembly.instantiate requesting env.memory and env.table. Should trigger the Wasm threat signal.
